# ADR-0004 - Versionado

Estado: Aceptado

La Suite posee su propia versión.

Cada Plugin posee su propia versión.

Cada módulo puede evolucionar independientemente.

Formato

Major.Minor.Patch

Ejemplo

Suite 1.2.0

Gain 0.4.1

Analyzer 0.2.0
